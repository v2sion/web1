## 3. 대화 원문을 살리려면 (권장 순서)

1. **claude.ai/code 접속** → `SESSIONS.md`의 링크로 세션을 연다.
   `https://claude.ai/code/<세션ID>` 형식이며, 표에서 바로 클릭 가능합니다.
2. **우선순위대로 처리.** 74개 전부는 부담스러우니 `SESSIONS.md`의 주제별 분류를 활용하세요.
   가장 값어치 있는 쪽은 기획·의사결정 맥락이 쌓인 세션입니다:
   - `[MVP] 초기 히스토리` 계열 (초기 설계 결정)
   - `[업데이트] 기능 및 방향성 개선` 계열 (제품 방향 변경 이력)
   - `새로운 앱 방향 기획 및 실행 전략 수립`, `백로그 정리: 게임 및 커뮤니티 앱 아이디어`
   - `[디자인]Global System`
3. **아카이브된 25개 세션**은 UI에서 안 보일 수 있습니다.
   필요하면 `unarchive_session`으로 되살릴 수 있으니 말씀해 주세요 (세션 ID는 `sessions.json`에 있음).
4. 꺼낸 내용은 이 `claude-backup/` 폴더에 마크다운으로 넣고 커밋하면 영구 보존됩니다.

## 5. 재해 복구 메모

Routines는 `routines.json`의 `prompt` 값과 `cron_expression`을 그대로 써서 재생성하면 됩니다.
cron은 **UTC 기준**이므로 KST 환산값을 `cron_note`에 같이 적어뒀습니다.

- `뉴스레터 아침 브리핑`: `0 23 * * 0-4` (UTC) = 월~금 08:00 KST
- `운동 일지 체크인`: `0 1 * * 1-5` (UTC) = 월~금 10:00 KST
