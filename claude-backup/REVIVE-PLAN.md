## 0. 전제가 바뀌었습니다

모바일 앱에서 과거 세션의 **대화 내용이 실제로 보인다**는 것은,
원문이 서버에 살아있다는 뜻입니다. 앞선 백업에서 "불가"로 적은 것은
**"제 도구로는 못 읽는다"**는 뜻이지 "사라졌다"가 아니었습니다.

그래서 이 문서는 **보이는 것을 어떻게 파일로 떨어뜨릴 것인가**만 다룹니다.

## 1. 막힌 길 (검증 완료 — 재시도 불필요)

| 경로 | 결과 | 근거 |
| --- | --- | --- |
| 제 MCP 도구로 대화 읽기 | ❌ 도구 자체가 없음 | `list_sessions`/`get_session`만 존재. 2회 재조회, 표본 2건 교차검증 |

**결론: 제가 서버에서 직접 가져오는 방법은 없습니다.**

## 2. 뚫린 길 — 세션이 스스로 뱉게 한다 ⭐

메커니즘은 **이미 이번 세션에서 검증됐습니다.** 아티팩트 19건을 제가 읽어서
레포에 저장한 것과 정확히 같은 경로입니다.

```
① 사용자가 앱에서 세션을 열고 프롬프트 한 줄 전송
        ↓
② 그 세션의 Claude가 자기 대화를 마크다운으로 정리해 아티팩트로 게시
        ↓
③ 제가 Artifact list → read 로 가져옴   ← 이 단계는 검증 완료
        ↓
④ 제가 claude-backup/transcripts/ 에 저장하고 커밋
```

사용자가 하는 일은 **세션당 메시지 한 개**뿐입니다. 나머지는 제가 합니다.

### 붙여넣을 프롬프트

```
이 대화의 처음부터 지금까지 전체 내용을 마크다운으로 정리해서
아티팩트로 게시해줘.

- 제목은 "[백업] " + 이 세션 제목
- 내 발언과 네 답변을 순서대로, 요약하지 말고 원문 그대로
- 툴 실행은 "무엇을 왜 했는지" 한 줄 요약 + 중요한 결과값만
- 코드/파일 내용은 코드블록으로 그대로
- 맨 위에 세션 제목, 날짜 범위, 결론 3줄 요약
```

> ⚠️ **먼저 1건으로 검증하세요.** 세션이 자기 과거 대화를 실제로
> 얼마나 온전히 재현하는지는 열어봐야 압니다. 아래 3-A의 클라우드 세션
> 하나로 2분이면 확인됩니다. 재현이 부실하면 4번 대안으로 갑니다.

### 4-A. 수동 복사 절차 (확정)

1. 앱에서 세션을 엽니다 — **새 메시지를 보내지 마세요**, 그냥 스크롤만 합니다
   (전송을 시도하면 오류만 뜨고 아무것도 얻지 못합니다).
2. 대화를 위에서 아래로 훑으면서 **Write/Edit 툴 호출 블록**을 찾습니다.
   각 블록에는 파일 경로와 그 파일의 전체 내용(또는 diff)이 들어 있습니다.
3. 파일 경로 + 코드 내용을 그대로 복사해서 저에게 붙여넣어 주세요.
   (형식 안 맞아도 됩니다 — 제가 파일 경로를 인식해서 정리합니다.)
4. 한 세션에 파일이 많으면 나눠서 여러 번 보내주셔도 됩니다.
5. 제가 받는 대로 `claude-backup/recovered-code/<세션 제목>/` 아래 실제
   파일로 복원하고 커밋합니다.

**우선순위는 위 표 그대로**: MVP 첫 출시(최초 전체 스캐폴드) → 09월 최신
업데이트 순으로 진행하면 됩니다.

### 4-B. 병행 권장 — 공식 데이터 내보내기 (5-1)

## 4. B·C(브리지 68건)를 살리려면 — PC 복귀가 선행 조건

브리지 세션은 **사용자 PC를 계산 환경으로 쓰는 세션**입니다.
PC가 사라져서 `computer_unreachable`이 된 것이라, 재개하려면 컴퓨터가 다시 붙어야 합니다.

1. PC(또는 새 PC)에 Claude Code 설치
2. **같은 계정**(v2sioninmymind@gmail.com)으로 로그인
3. Remote Control 연결
4. 앱에서 B 목록 중 **한 건만** 먼저 열어 재개 시도
5. 되면 → 2번 프롬프트로 아티팩트 게시 → 저에게 알려주세요

> **주의:** 재개된 세션이 과거 대화를 온전히 갖고 있을지는 확실하지 않습니다.
> 로컬 트랜스크립트(`~/.claude/projects/*.jsonl`)는 PC와 함께 지워졌고,
> 서버가 보관한 표시용 이력을 어디까지 복원해 주는지는 열어봐야 압니다.
> **그래서 4번은 반드시 1건 시험 후 판단합니다.**
